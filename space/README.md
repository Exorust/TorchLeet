# TorchLeet

Browse 65 PyTorch and LLM interview problems, then solve them in a real
JupyterLab — no install, no signup.

- `/` — searchable catalogue (filter by track, difficulty, company)
- `/lab` — full JupyterLab with every notebook and the `torchleet` grader
  preinstalled

`problems.json` is generated from the repo's `problem.toml` manifests
(`python3 scripts/generate.py json`), so this Space cannot drift from the
source of truth.

Source: https://github.com/Exorust/TorchLeet
